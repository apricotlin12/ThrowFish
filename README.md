# ThrowFish — 今天，丟一條魚。

純前端像素小遊戲。抓住魚往後拉，放開丟向烤箱；整條魚完整停在烤盤上拿到 60 分，每完整翻轉一圈再加 10 分，翻轉分與總分沒有上限。

## 本機啟動

需要 Node.js 24 與 pnpm 11.25.0（`npm install -g pnpm@11.25.0`）。

```sh
pnpm install
pnpm dev
```

開啟終端機顯示的本機網址。`pnpm test` 執行評分與物理驗證，`pnpm build` 執行 TypeScript 檢查並產生 `dist/`，`pnpm preview` 預覽建置成品。

建置也會產生自帶全部程式與樣式的 `dist/play.html`，可以直接用瀏覽器開啟試玩，無需啟動本機伺服器。最高分在這個檔案與網站網址之間不會共用；若瀏覽器不允許檔案儲存紀錄，仍可正常遊玩。

## 操作與計分

- 滑鼠或單指按住魚，往出手方向的反方向拖曳，再放開。
- 抓魚中央較穩定；抓頭尾／偏離中央會產生旋轉。
- 按 R 或點「重新開始」重來；按 M 或點音效按鈕切換音效。
- 未完整入爐 0 分、完整入爐但未上盤 40 分、完整停穩在盤上 60 分。
- 每完整翻轉一圈 +10，圈數與總分不設上限；高拋或有效彈跳 +10；中央平穩落盤 +10。
- 花式只記錄到首次接觸烤盤，且必須最後整條魚完整落盤才入帳。

本機最高分與音效偏好存於 localStorage；資料清除或換裝置後不會保留。音效由 Web Audio 即時合成，像素素材由 Canvas 繪製，沒有外部圖片、字體或音效服務。

## 登記與排行榜

玩家投擲結束後，可填寫暱稱或留白，再按「登記這次分數」。每次投擲只登記一次，記錄保存在目前瀏覽器的 localStorage；重新開始不會清除登記紀錄。瀏覽器儲存失敗時會提示可能遺失。

此版本採用「蒐集後由 Codex 填表」的流程，不使用 Apps Script 或玩家 Google 登入。玩家介面只提供選填暱稱、登記和排行榜，沒有匯出或同步操作。**登記按鈕不會自動將資料傳到 Google Sheets，也不會集中蒐集其他玩家瀏覽器的紀錄。** Codex 只能整理當前可存取的瀏覽器紀錄。

紀錄與試算表 A:E 欄位依序對應：`暱稱`、`分數`、`空中翻轉`、`高拋路線`、`完美落盤`。分數是總分；後三欄存加分數值，高拋路線欄包含高拋／彈跳共用加分。暱稱空白保持空白，排行榜顯示「無名丟魚手」。

整理者可在同一瀏覽器開啟遊戲網址加上 `?records=1`，檢視本機登記紀錄；正常遊戲頁不顯示這個檢視。整理時先檢查是否已匯入，再填入空白列，不覆寫表頭與既有資料。這個檢視沒有遠端讀取其他玩家資料的能力，也不會自行寫入試算表。

排行榜直接讀取使用者指定的公開試算表 `工作表1`（gid=0）A:B 欄，依數字總分由高至低顯示前三筆；同分不合併，同暱稱的不同投擲也不合併。按「更新」取得新資料，網路失敗可重試，不會以本機紀錄冒充全球排行。遊戲不提供試算表跳轉連結；讀取仍依賴該試算表的公開檢視權限。

## GitHub Pages

1. 將此專案放進 GitHub repository，推至 `main` 或 `master` 分支。
2. 在 repository 的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。
3. 專案內的 `.github/workflows/deploy.yml` 會測試、建置並發布；也可在 Actions 手動執行。
4. 部署完成後開啟該 workflow 的網站網址即可遊玩。

Vite 使用相對資源路徑，支援 `https://使用者.github.io/專案名稱/`。沒有後端、資料庫或金鑰。初次載入需要網路，尚未提供離線快取。若自行部署，將 `dist/` 的全部內容交給任何靜態網站主機即可。

## 結構

| 檔案 | 用途 |
| --- | --- |
| `src/main.ts` | 輸入、畫面狀態、結果與本機紀錄 |
| `src/physics.ts` | Matter.js 固定時間步長的投擲與碰撞 |
| `src/scoring.ts` | 全魚入爐、落盤、花式與配分 |
| `src/renderer.ts` | 像素廚房、魚與粒子 |
| `src/audio.ts` | 合成音效 |
| `GAME_SPEC.md` | 原始討論規格 |

採單一魚剛體與視覺受撞變形。物理每秒 240 次更新，畫面依裝置更新率繪製；分頁隱藏或失焦時暫停。提供試算表前三名排行榜，暫不包含關卡或完整烹飪系統。

## 驗證紀錄

- 評分、物理與紀錄測試覆蓋 60 分普通投擲、超過 100 分、未落盤不加分、魚尾伸出、超時、旋轉計數、選填暱稱、重複登記與數字排行。
- 本機 Chromium 預覽已實際拖曳取得 100 分，並確認失敗花式不入帳、重新開始、R／M 快捷鍵、最高分重新整理後保留與無主控台錯誤。
- 手機寬度的響應式畫面已檢查；尚未以真實手機觸控或 Safari／Firefox 驗證。
- 單檔版已產生；內建瀏覽器禁止 `file://` 網址，因此直接開啟單檔的行為未能自動驗證。

部署方式參考 [Vite 靜態部署文件](https://vite.dev/guide/static-deploy.html)，物理 API 參考 [Matter.js 文件](https://www.brm.io/matter-js/docs/)。
